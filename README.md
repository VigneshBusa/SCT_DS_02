# Titanic Dataset - Exploratory Data Analysis

## Project Overview
This project performs data cleaning and exploratory data analysis (EDA) on the Titanic dataset.

## Objective
To analyze passenger data, clean missing values, and identify patterns related to passenger survival.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Google Colab

## Features
- Data cleaning
- Missing value handling
- Survival analysis
- Data visualization

## Dataset
Titanic Dataset

## Output
Generated visualizations and analysis on passenger survival patterns.
